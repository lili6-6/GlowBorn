# GlowBorn
2d平台跳跃游戏
开发时间：2025.8-2025.11
简介：此游戏是一款pc端横板冒险游戏，玩家扮演的萤火虫将在被侵袭的黑暗森林里，救助伙伴，点亮森林，击退黑暗
说明：此项目基本逻辑基于CorgiEngine开发，此外，实现了玩家四形态转换，多技能系统，场景内景物的交互系统，场景内伙伴的交互系统，小怪系统，boss行为决策系统等多模块。
 其中:
  形态转换与技能是继承CorgiEngine的CharacterAbility进行开发，实现形态轮换，不同形态对应不同的待机和主动技能，比如：发射烟花，加速，治愈，除对自身增益外，还可触发场景内景物的交互（绿色形态下走过藤曼旁 藤曼自动开花），或者治愈npc等等功能；
  场景交互通过Property系列脚本实现，由Property_base定义共通功能，具体功能通过Property_继承base具体实现，Property_Animation管理动画。同理，游戏中npc也按照这个逻辑开发。此外，地面等交互对象提前预留了多人触发的机制，防止多人同时交互时出现状态混乱的情况
  
  分工说明：此项目由三位美术同学、我和另一位技术同学开发。分工上另一位负责主菜单，设置面板，以及玩家血条适配相关逻辑，其余技能适配，动画适配，场景适配以及其他功能均为本人开发
